# Git Commit & Push Rule

Whenever you make any changes to the source code, configurations, or any files in this project, you MUST ALWAYS commit and push the changes to GitHub (`dottoroku` remote / `main` branch).

1. Review what changes you made.
2. Run `git add .` to stage the changes.
3. Run `git commit -m "Descriptive commit message"`
4. Run `git push` to upload the changes.

Do this automatically as a final step of any implementation or bugfix task.
